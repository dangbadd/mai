# Mai

A personal desktop companion for Windows: a virtual character that lives on the user's screen for entertainment.

## Language

**Mai**:
The name of both the app and its single, fixed Character.

**Character**:
The virtual figure shown on the user's desktop, drawn as 2D sprites.
_Avoid_: Mascot, pet, avatar, nhân vật ảo

**Animation**:
One named behavior state of the Character (e.g. idle, walk, sleep, dragged), shown as a sequence of sprite frames.
_Avoid_: Motion, action, pose

**Ground**:
The horizontal line the Character stands and walks on: the top edge of the taskbar, or the bottom of the work area when the taskbar is elsewhere or auto-hidden.
_Avoid_: Floor, baseline

## Versions

**Release**:
An official version of Mai; the only event that raises the major number `x` in `x.y.z`.
_Avoid_: Launch, ship

**Feature update**:
A version that adds new features, raising `y`.

**Patch**:
A version with only fixes or small improvements to existing features, raising `z`.
_Avoid_: Hotfix, minor update
